# Классификатор ориентации текста

Решение тестового задания Avito DS Bootcamp 2026: компактная CNN определяет,
находится ли текст на изображении в нормальной ориентации или повёрнут на 180°.
Обучающая выборка генерируется автоматически из русских и английских слов.
Модель обучается с нуля с использованием BCE-функции потерь. Её предсказание —
вероятность того, что текст перевёрнут.

Датасет содержит русские и английские слова и фразы, числа, даты, URL и
идентификаторы, отрисованные разными шрифтами, цветами и стилями. Часть изображений дополнительно размыта, уменьшена и сжата в JPEG.

## 📊 Результаты

- синтетический датасет: 50 000 обучающих и 5 000 валидационных изображений;
- 295 297 параметров в модели;
- лучший BCE loss на валидации — **0,0642** (37-я эпоха);
- обучение остановлено досрочно после 42 эпох;
- результаты авторского прогона доступны в файлах `best_model.pt` и
`submission.csv`.

## 🚀 Запуск

Нужен Python 3.11. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Скачайте тестовые изображения и поместите их в каталог `test/`. Затем откройте `solve.ipynb` и выполните все ячейки по порядку

Ноутбук сам скачает шрифты, сгенерирует датасет, обучит модель и создаст
`best_model.pt` и `submission.csv`. При наличии CUDA обучение выполняется на GPU.
